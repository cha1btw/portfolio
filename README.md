# Portfolio

Personal site: websites and Telegram bots for small business, plus a CV page.
English at `/` (default), Ukrainian at `/uk`, CV at `/cv` and `/uk/cv`.

## Run

```bash
npm install
npm run dev
```

## Where to edit

- `lib/site.ts`: contacts (Telegram, email, LinkedIn), project links, status labels, service prices.
- `content/uk.ts`, `content/en.ts`: every visible text.
- `public/work/*.jpg`: project screenshots (1440x720, taken with headless Chrome).
